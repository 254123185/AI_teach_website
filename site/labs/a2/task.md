# 用同一批任务选模型

两组模型在相同短任务上的模拟测量保存在 `runs.csv`。请让 Agent 搭一个可重复的比较工具。

实现 `summarize(rows)`，返回字典，以模型名为键，每个模型统计 `accuracy`、`median_ttft_ms`、`cost`。`correct` 的 "1" 表示通过，"0" 表示失败。首字延迟取中位数，成本为全部任务用量之和。拒绝模型组之间任务集合不同或同一组内任务重复的输入。

运行 `python -m unittest -v` 和 `python solution.py`。报告最后用一行写出选择依据。本例的硬门槛是正确率至少 0.9，通过后按首字延迟由低到高排序。文件里的测量值是教学设定。
