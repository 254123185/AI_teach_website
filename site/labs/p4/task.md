# 复核低照度图像降噪实验

先打开 `published/demo.html` 和 `published/report.md`。用随包的证据做下面的交接任务，复算适合需要核对像素或实现时再做。

## 交给 AI 的评审任务

请让 Agent 根据 `protocol.json`、`scene.py` 和 `published/result.json` 写一页备忘录。先指出固定 50% A/B 混在一起的两个因素，再用同均值对照分别解释暗墙和木纹。请它用木纹的 MAE 和反差比说明为什么不能仅凭一项读数判断细节变好。结尾列出这个教学样本的两个前提，以及缺少干净参考图时应该暂缓汇报的指标。

由你抽查一个坐标和两条数字。接下来如果只能补一组实拍，决定先采跨边界纹理、移动灯芯还是行相关噪声，并写明你要排除的是哪一种误判。

## 可选复算

本包附有确定性实验实现。读 `protocol.json`、`scene.py` 和 `solution.py` 后，可以复算发布页面用的同一组输入、支路、融合结果和评审数据。

```
python -m unittest -v
python solution.py --out run
```

打开 `run/demo.html` 即可在浏览器查看对照。结果表是固定权重与分区权重的比较，选择器只切换要看的版本和同坐标裁剪。检查 `run/result.json` 的完整精度与 `run/manifest.json` 的文件校验值。可使用随包的运行快照核对实验编号与各文件 SHA-256。

工程师可以在核对后把新的权重规则另存为独立实验。原版使用 8 位合成灰度低照度样本，分区位置由人工预设。实拍样本和真机性能需要另行验证。
