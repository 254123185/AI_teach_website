# 复算夜景茶铺分区融合实验

本包附有已经完成的确定性实验实现。先读 `protocol.json`、`scene.py` 和 `solution.py`，再复算发布页面用的同一组输入、两个分支、两个候选和评审数据。

```
python -m unittest -v
python solution.py --out run
```

打开 `run/demo.html` 即可在浏览器查看对照。结果表是固定权重与分区权重的比较，选择器只切换要看的版本和同坐标裁剪。检查 `run/result.json` 的完整精度与 `run/manifest.json` 的文件校验值。可使用随包的运行快照核对实验编号与各文件 SHA-256。

## 交给 AI 的复核任务

请让 AI 复核 A、B 是否复用了同一份弱强输出，指出空间权重是否读取了参考图或评估 ROI。让它从暗墙、木纹、灯芯和交界各取一个例子，说明为什么该指标对应本区风险。检查是否存在未达到预设门槛的项目，列出对该失败项的最小下轮实验。保留固定协议、原始候选和失败结果。

工程师可以在核对后把新的权重规则另存为独立实验。原版仍是 8 位合成灰度算例，空间位置人工预设，同时没有独立留出拍摄或真机测量。
